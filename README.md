# Sitio web Pop It

## Descripción

Este proyecto consiste en una página web dedicada a los juguetes Pop It. La idea es mostrar algunos de sus diseños, presentar sus características y crear un espacio visualmente atractivo, con colores llamativos e imágenes relacionadas con estos juguetes.

La página está organizada en varias secciones: inicio, productos, información y galería. También cuenta con botones interactivos para que el usuario pueda seleccionar el producto que más le interese.

## Tecnologías utilizadas

* **HTML5:** para organizar el contenido de la página.
* **CSS3:** para los colores, el diseño, los fondos y la adaptación a diferentes tamaños de pantalla.
* **Flexbox:** para organizar elementos como la cabecera y algunas secciones.
* **CSS Grid:** para distribuir las tarjetas de productos y las imágenes de la galería.
* **JavaScript:** para agregar interacción a los botones.

## Organización del proyecto

* `index.html`: contiene la estructura principal del sitio.
* `styles.css`: contiene los estilos y el diseño visual.
* `scripts.js`: controla la interacción de los botones.
* `fondo.png`: se utiliza como fondo principal de la página.
* `images/`: contiene las imágenes utilizadas en las diferentes secciones.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` directamente en el navegador o utiliza la extensión Live Server.
4. Explora las secciones y prueba los botones de los productos.

## Publicación

El proyecto se encuentra alojado en GitHub y se puede publicar mediante Netlify para acceder al sitio desde un navegador, sin necesidad de ejecutar los archivos localmente.

## Objetivo

El objetivo de este trabajo es poner en práctica los conocimientos de HTML, CSS, Flexbox, Grid y JavaScript mediante la creación de una página web sencilla, organizada y agradable a la vista.
